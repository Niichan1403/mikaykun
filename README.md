# Voxelize Tool

A browser voxelizer: drop in a model, get a coloured block build you can inspect and export.

**Live:** https://niichan1403.github.io/mikaykun/voxelize-tool/

Takes FBX, GLB, GLTF and OBJ, plus PNG and JSON for palettes and recipes. Everything runs in the
browser - models are read and voxelized locally and nothing is uploaded anywhere.

This repository holds only the built static site. The source lives elsewhere.
