The app shows its own version in the header and on the sign-in screen. Everyone working on one collection should be on the same one. All versions

Windows will warn you. That is expected.

The installer is unsigned, so Windows shows “Windows protected your PC”.

  1. Click More info
  2. Click Run anyway

Your browser may warn on the download too. Choose Keep.

First run

  1. Open the app and click Sign in with Google. It opens your browser.
  2. Pick your work account. The browser says to come back; the app is signed in.
  3. If it says the address is not on the list, ask an admin to add it, then sign in again.

For the Unity import

The Import tab needs two paths that differ per machine:

  • the Unity editor (Unity.exe)
  • the game project folder

Set them once; they are remembered. Close Unity before importing — a running editor holds a lock that blocks batch mode for up to thirty minutes.

Updates

The app checks on start and offers the new version. Settings → This app checks on demand and installs.

Only need to look at a board? Open the viewer in your browser — no install, no sign-in, no saving.
