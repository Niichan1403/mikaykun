Cube Blast 3D Level Engine

Level configs, boards, shooter queues and the Unity import, in one app.

Download for Windows
Windows 10 or 11, 64-bit · installs for your user only, no administrator rights needed

Windows will warn you, and that is expected.

The installer is not code-signed, so Windows shows a blue box saying “Windows protected your PC”. It is not a virus warning — it means Windows has not seen this file from a paid certificate before.

  1. Click More info (small text, easy to miss)
  2. Click Run anyway

Your browser may also warn on the download itself. Choose Keep.

After it installs

  1. Open Settings and connect to the team database, if it is not already.
  2. Sign in with your work email. A link arrives by email; click it.
  3. Wait to be approved. Signing in is a request — a new account sees nothing until an admin approves it. Ask whoever runs the tool.
  4. Once approved, the colour atlas and palette download automatically and everything works.

For the Unity import

The Import tab needs two paths that are different on every machine:

  • the Unity editor (Unity.exe)
  • the game project folder

Set them once in the Import tab; they are remembered. Close Unity before importing — a running editor holds a lock that blocks batch mode for up to thirty minutes.

Updates

The app checks for a new version on start and offers it. You do not need this page again.

Only need to look at a board, not build one? Open the viewer in your browser — no install, no sign-in, and no generating or saving.
